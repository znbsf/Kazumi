# TV 默认设置审查

适用：TV 预览版 2.3.0（203004）。保留原有 Material 3 配色、卡片和播放器内核。

## 默认值，不是强制重置

统一通过 `SettingKey` / `GStorage.getSetting` 解析电视默认值：已有、类型正确的
个人设置优先。首次安装及对应页面“恢复默认设置”使用 TV 默认值；升级不静默覆盖。
旧设备若想使用整套播放默认值，可在“我的 → 播放设置”恢复默认。

| 设置 | 手机版原默认 | TV 默认 | 理由 |
| --- | --- | --- | --- |
| 低内存模式 | 关 | 开 | 为小内存电视限制压缩数据缓存 |
| 缓存上限（前向 / 回看） | 普通模式各 1500 MiB；低内存各 2 MiB | 低内存 64 / 16 MiB；普通 256 / 64 MiB | 避免过大缓存，也避免直接套用 2 MiB 使网络抖动过于敏感 |
| 播放器过渡动画 | 开 | 关 | 降低动画负担；焦点边框仍保留 |
| 控制栏隐藏等待 | 4 秒 | 7 秒 | 为 D-pad 连续移动留时间 |
| 亮度 / 音量滑动手势 | 开 | 关 | 遥控器使用按键；系统音量仍由 Android / CEC 处理 |
| 弹幕默认开启 | 关 | 开 | 初次播放即可验证弹幕，可随时关闭 |
| 弹幕区域 / 字号 / 去重 | 全屏 / 紧凑布局 16，否则 25 / 关 | 上半屏 / 24 / 开 | 留出内嵌字幕区域、保持远距离可读性 |
| 下载并发：剧集 / 分片 | 2 / 3 | 1 / 2 | 减少电视后台并发负担 |
| 启动时检查上游应用更新 | 开 | 关 | TV 不应被引导安装上游手机 APK |

缓存数字是 mpv 压缩数据缓存上限，不是启动即占用这么多，也不是总进程内存上限。
计费网络的在线播放仍将前向和回看各限制为 2 MiB；本地文件不受计费网络限制。
这些预算是保守起点，不代表所有芯片的长时间内存/卡顿实测结论。

## 大屏、解码与保留项

- 当前大屏布局由 `utils/device.dart` 自动判断，旧 `isWideScreen` 存储键不再是有效开关。
  TV 现在明确进入大屏布局，避免低逻辑分辨率电视掉回紧凑手机布局。
- 硬件解码继续开启、解码器继续 `auto-safe`；TV 自动渲染器沿用已适配的
  `mediacodec_embed`。保留显式渲染器/解码器选择。
- 超分辨率继续默认关闭；直连 Surface 的兼容性限制不变。
- OpenSLES 音频本次不改：没有新证据支持把所有电视统一改为另一种音频输出。
- 续播、自动下一集继续开启；倍速、比例、音量不强改。后台播放、自动画中画、
  海量弹幕继续关闭。显示模式页面是刷新率选项，不是大屏开关，继续自动。
- 主题/字体/OLED、代理、规则更新、WebDAV、Bangumi、追番和同步账户设置保持原样；
  不启用新的联网或账号同步。日志等级和调试开关保持原样。
- 历史在 TV 左栏“推荐”下方常驻，也可选为启动页；手机版底栏及右上角入口不变。
- TV“检查更新”打开本 fork 的 Releases；即使旧设置开启自动更新，也不会访问
  上游应用更新镜像。暂不实现预览版的后台自动下载安装。

## OK 与焦点约定

1. 控制栏隐藏：OK / 下键唤醒并聚焦播放/暂停，上键唤醒并聚焦选集；唤醒不暂停。
2. 控制栏显示：方向键移动焦点，OK 只执行当前控件；媒体播放/暂停键仍直接操作。
3. 关闭子面板后，即使焦点返回快捷键根节点，OK / 方向键也可重新进入可见按钮。
4. 返回按层关闭对话框、选集/菜单、控制栏，再退出播放。发送弹幕只有明确按 OK
   打开输入对话框时才召唤软键盘，经过发送按钮不会弹键盘。

测试入口：`tv_defaults_preview_test.dart`、`tv_player_shortcuts_test.dart`、
`danmaku_fixture_simulation_test.dart`；实际验证见对应 Release 说明。
