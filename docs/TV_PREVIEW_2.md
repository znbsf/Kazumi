## 相对 Preview 1 的更新

- TV 详情页移除右下角播放/吐槽悬浮按钮，在标题下、海报右侧集中放置开始观看、追番和吐槽；保留原主题、圆角与评分信息。
- 默认聚焦开始观看，左右循环，上下连接返回按钮和页签；加载占位不遮挡操作区。
- 追番菜单打开后可用方向键移动，短返回只关闭菜单并恢复入口焦点。
- 详情页 Play / PlayPause 与开始观看共用入口：优先恢复历史，没有可用历史才选源。
- TV 选集面板去掉内层不透明底色；四列选集支持行内循环、末行向下回首行，上键保留页签出口。
- 播放器底栏集中排列，选集就在播放键旁；上下连接两排控件，左右首尾循环。
- 播放器提供可见主页入口；TV 长按返回约 1 秒后松开回应用主页，系统 Home 不变。
- 保留左栏历史、横向分类、LCN 数字直达与限时查找、遥控器说明、显式弹幕输入、原有 TV 默认配置和播放诊断。手机版布局分支保留。

## 本地示例弹幕

本包继续嵌入附件 `tv_preview.json` 的合成数据，所有提示标注 **[本地示例]**。
它不是当前节目的在线评论。未配置 `DANDANAPI_APPID` 与 `DANDANAPI_KEY`，无法完成在线 API 签名；
只有 AppID 不够，未配置凭证不代表弹弹 Play 服务故障。

每分钟六条稀疏提示覆盖前四小时，用于暂停、seek、续播与遥控器测试。
CC / 红键可开关弹幕；“我的 → 弹幕设置 → 本地示例弹幕”可关闭示例，重新进入播放生效。
关闭示例不会自动恢复在线弹幕；普通构建不嵌入此文件，示例不发送到服务器、不写入下载缓存。

## 实际验证

- 发布前完整 Flutter 测试集 **216 项通过**，修改的 Dart 文件静态分析无问题。
- 同一 203010 APK 已安装 Google TV API 36 AVD 与 MiTV-ASTP0 / Android 9，安装后哈希核对一致。
- 真机通过：详情主操作焦点/循环、追番菜单返回、明确选源后第 1 集真实出画、媒体 Play 恢复同来源同集进度并继续出画。
- 真机通过：OK 唤醒、选集入口、浅色透明面板、选集首尾循环、发送弹幕聚焦不弹键盘、可见主页按钮返回 LCN。
- 真机操作使用 ADB 注入键码，不等于实体遥控器的全部硬件键/长按已验证。
- 这轮没有新增手机版 APK 或重新执行手机版设备验收。详细证据和历史测试边界见[焦点回归记录](TV_FOCUS_REGRESSION.md)。

## 已知问题与未验证范围

1. **首页返回侧栏仍有问题：**首列卡片左键可能转到顶部分组并切换分类，未稳定回到侧栏；下一版优先修复。
2. **选集存在相似双描边：**正在播放的集数与当前遥控焦点都显示粗绿色框，待区分样式。
3. 部分来源的验证码图片加载、输入/按钮定位或成功检测仍有问题。本版未修复；见[诊断待办](TV_CAPTCHA_DIAGNOSTIC_PLAN.md)。不要公开原始日志、Cookie、验证码答案、密钥或鉴权链接。
4. 实体遥控器至少 900 ms 的长返回仍待人工验证；Google TV AVD 已有该路径验证，可见主页入口已在真机验证。厂商提前拦截的系统键不保证送达应用。
5. 未验收全部来源、全机型、4K/HDR、长期音画同步/内存表现及官方在线弹幕端到端。短程出画不等于流畅性或硬解性能验收。
6. 手机与电视的节目、来源、集数和时间点接力仍是第二阶段，本包不包含。

## 发布后 UI 审查补充（2026-09-06）

本段是发布后的文档补充，**不是 203010 APK 新增修复**；APK、哈希与发行标签不变。

- TV 搜索输入区域的后代焦点被禁用，需验证入口是否可达，以及 OK 唤起键盘与逐层返回。
- 历史卡片整体聚焦时，内部详情、追番与删除操作可能不可达；编辑模式 OK 目前只有提示。

上述两项尚未完成设备复现，不写成确定故障或修复完成。侧栏文字、续播提示、播放器 / 选集入口、
选源双栏和加载反馈等也只列入计划，详见 [当前 UI 待办与证据状态](../README.md#ui-plan)。
发行标签中的文档是发布时快照；当前分支文档包含后续审查，二者时间范围不同。
