# Kazumi TV 2.3.0 — Preview 1

非官方 TV fork 公开测试版，不是上游手机版，也不是稳定版。
包名 `com.znbsf.kazumi.tv`，versionCode `203004`，可与手机版共存。

## 本轮变化

- OK / 下键固定唤醒播放按钮，上键定位选集；可见控件交给正常焦点操作。
- 修复左栏返回通路，历史加入左栏；历史也可设置为启动页。
- 沿用原有风格，加入 TV 默认缓存预算、下载并发、控制栏停留和弹幕设置。
- TV“检查更新”转到本 fork，不再推荐上游手机 APK。
- TV APK 使用独立原创几何电视标识，不打包上游单独授权的人物图标；内部 UI 风格不变。
- 保留横向分类、节目编号直达、半透明选集、遥控器说明及硬件解码诊断。

## 本地示例弹幕：请先读

此 APK 将 `tv_preview.json` 合成弹幕编译打包进去；每条都带有 **[本地示例]**。
它不是当前剧集的真实评论，仅用于显示、暂停、拖动进度和遥控器测试。
本包没有配置 `DANDANAPI_APPID` 和 `DANDANAPI_KEY`，无法完成在线 API 签名。
只有 AppID 不够；这不意味着弹弹 Play 服务发生故障。

每分钟重复六条稀疏提示，覆盖前四小时，方便从历史中间进度恢复测试。
CC / 红键可关闭弹幕；“我的 → 弹幕设置 → 本地示例弹幕”可关闭示例，重新进入播放生效。
关闭示例不会恢复在线弹幕，仍需完整 API 凭证。若已有完整凭证或播放已下载的本地文件，
示例不覆盖正常路径。不写入下载缓存、不发送到服务器，普通构建不嵌入此文件。

## 安装与反馈

下载包含 `TV`、`preview.1` 的 universal APK，支持 armv7 / arm64 / x86_64。
使用本 fork 当前测试签名；如更换正式签名，会另行说明迁移方式。
升级原测试版保留历史、规则和设置。已保存设置优先于新版默认值；如需整套新默认值，
可在播放设置中恢复默认，见 [设置审查](TV_DEFAULTS.md)。

在本 fork Issues 反馈电视型号、Android/APK 版本、按键序列、预期/实际行为；
播放故障可补充 INFO 页解码器、输出、缓存与丢帧。不要公开账号、API Key、鉴权链接或私人日志。
尚未宣称全机型、HDR/4K、长时稳定性通过。手机向电视传递源、节目、时间点仍为下一阶段。

```powershell
./scripts/build-tv-preview.ps1 -Flutter flutter -BuildNumber 203004
```
