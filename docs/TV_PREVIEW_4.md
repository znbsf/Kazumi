# Kazumi TV 2.3.0 — Preview 4

非官方开源 TV fork 的第四个公开测试版，**不是稳定版**。
本版修复首页海报列表“下滚后向上不回滚、焦点移出画面”的 UI-14 问题，
保持原有配色、圆角、卡片尺寸、横向分类和 libmpv / media-kit 播放内核。
手机与 TV 接力播放仍未实现。

## 本次修复

- **双向自动滚动：**按行位置计算海报可见范围，再移动焦点；向上和向下都能显露目标，并避开固定分类栏。
- **单一滚动控制：**TV 首页不再同时执行通用卡片自动滚动，避免两个滚动请求相互干扰；其他页面和手机版默认行为不变。
- **快速输入：**新方向取消过期动画 / 焦点请求，长按累计待到达条目，快速反向、转到侧栏或打开详情后不被旧请求抢回。
- **焦点恢复：**侧栏和详情返回也会显露原海报；长距离循环时处理旧卡片回收与临时焦点回退。
- 新增 **14 项首页专项测试**，补齐原来未覆盖的长列表反向、固定分类栏遮挡和异步导航边界。
- README 更新到本版，增加实体电视首页截图，清楚区分现有功能、已知问题和待办。

## 实际验证范围

- 发布前重新运行 **264 项 Flutter 测试，全部通过**，修改的 Dart 文件静态分析、差异格式及 APK v2 签名验证通过。
  早期轮次存在既有 AsyncRateLimiter 计时偶发失败记录；未修改该模块，不宣称消除了计时风险。
- **正常 203028 / Google TV API 36 AVD：**在线分页、55 → 49 → 1、侧栏 / 真实详情返回和快速反向通过。
- **独立离线 AVD 包：**120 条长列表、末行 115 回首行、原生长按与焦点位置检查通过；离线入口和样例未进入正常发行包。
- **同一 203028 / MiTV-ASTP0、Android 9、armv7：**保留数据覆盖安装，拉回 APK 哈希一致，原浅色主题和 13 条规则仍在。
  从已确认的 19 号下行到 55，上行到 49，再回到 1；侧栏 / 真实详情返回、快速反向、ADB 原生长按短程检查通过。
- 正常 APK 当次 AVD / MiTV 推荐与分页接口均有 HTTP 200，**不代表之前网络不稳定的根因已经解决**。
- 真机使用 ADB 注入键码，不等于手持实体遥控器的全键 / 持续长按验收。
  本次没有重新验证视频播放、音画同步、4K/HDR、长期内存稳定性或全机型兼容性。
- 本版 APK 是本地构建并经设备验证的产物，不是 GitHub CI 重建产物。

## 已知问题与弹幕说明

1. **初始焦点尚有疑点：**MiTV 初次启动后的首个 RIGHT 未见海报焦点框，首轮脚本落点与预设不符。
   确认实际起点后重测通过，但没有把初始焦点 / 唤醒阶段的原因列为已解决。
2. **UI-13：暂停 seek 后退出可能丢失新进度。**尚未修复；本轮不以改动用户播放历史的方式重现。
3. **UI-10：搜索网络失败可能显示为空结果。**错误反馈与重试入口仍待改进。
4. **UI-12：首次启动仍有上游更新渠道文案。**请使用本 fork 的 GitHub Releases，不要从 F-Droid 寻找本 TV 包。
5. 部分来源验证码、Bangumi 网络不稳定、实体遥控器特殊键 / 长返回、真机末尾循环仍待验证或定位。
6. **本版不包含演示弹幕，也没有注入在线弹幕 AppID / Key。**无弹幕不等于弹弹 Play 服务故障，在线端到端未验收。
   Preview 2 的合成示例不是本版功能；本地 fixture、样例历史、原始设备日志和凭证不作为本次发行附件。
7. 侧栏文字、续播提示、播放器常用 / 更多操作、选源双栏及手机联动仍在
   [README 计划](https://github.com/znbsf/Kazumi/blob/v2.3.0-tv-preview.4/README.md#ui-plan)，未冒充本次修复。
